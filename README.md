# Quizly UK question bank

England curriculum questions for KS1, KS2, KS3 and KS4/GCSE, sourced from Oak National Academy.

Only the supplied archive's English rows labelled OGL-UK-3.0 with valid source and attribution fields are included. Other sources and restricted Oak subjects are excluded. The original importer reports filtering restricted lessons. This publication validates the supplied metadata and does not independently re-query Oak's restriction API.

Question text and options are retained. Stable IDs and curriculum metadata were added, and duplicate or invalid rows were removed. Each row retains its original lesson source URL, licence URL and attribution.
